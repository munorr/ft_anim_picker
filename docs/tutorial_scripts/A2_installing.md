# A2 — Installing BGEN Picker

---

## Intro

Before we can build anything, we need the addon installed. BGEN Picker ships for both Blender and Maya, so I'll cover both — jump to whichever applies to you.

## Blender

Head over to the BGEN Picker download page and download from whatever platform you want. After downloading you'll get a zip-file — don't unzip it.

### First time only: install dependencies

If this is the first time installing BGEN Picker for your blender version you will need to install dependencies before proceeding.

On Windows, launch Blender **as Administrator** (right-click → Run as administrator). On Mac, a normal launch is fine.

Once blender is launched head over to; **Edit → Preferences → Add-ons** then click on the drop down arrow and select "Install from Disk". Locate the zip file and install it. 

The first time you enable it, you will be prompted to Install Dependencies. Click the button and wait for the progress bar to finish loading. Once dependencies are installed, restart blender and BGEN Picker will be ready to use.

A new drop-down menu labeled BGEN should be created at the top left, next to the Help menu. Open the BGEN Menu and Select BGEN Picker.

Look at the top menu bar — next to **File**, **Edit**, **Render**, and the rest, you'll see a new **BGEN** menu. Click it and choose **Picker**, and the main window launches.


## Maya

Download the BGEN Picker package and unzip it somewhere you're happy to keep it — the folder needs to stay where you put it, since Maya will load the addon from that location every session.

Open up that folder and drag the install file straight onto the viewport. The installer creates a **BGEN Picker** button on your currently active shelf, using the addon icon.

That's it — click the shelf button anytime you want to open the picker.

> **Tip:** The installer puts the button on whichever shelf is active when you drag the file in, so make sure the shelf you want is selected first. If you want the button on a different shelf later, middle-mouse-drag it across.

## First launch

The first time you open BGEN Picker, you'll see a launch dialog with three options: **create a new picker**, **open one from the library**, or **convert a legacy picker** if you've used older versions. We'll cover all three in the next few videos. For now, just close the window — you're installed and ready.
